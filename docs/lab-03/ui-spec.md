# UI Specification

## Theme
Reuses Lab 2 Zen Green design. Requires consistent badges, responsive tables/cards, and clear feedback states (loading, errors, success).

## Screens
1.  **Login & Change Password**: Minimalist form for login. Mandatory interstitial screen for initial password change.
2.  **App Shell**: Role-specific navigation. Displays current user and logout action.
3.  **IT Staff Queue**: Desktop table / mobile cards with search, priority/status filters, sorting, pagination.
4.  **IT Staff Ticket Detail**: Grouped read-only and editable (owner, priority, status) fields. Distinct sections for Public Comments and Internal Notes.
5.  **Requester Ticket Detail**: Lab 2 view plus Public Comments and "Problem Appears Resolved" action.
6.  **Admin User Management**: Searchable list view with inline or modal forms for creating/editing users and resetting passwords.
